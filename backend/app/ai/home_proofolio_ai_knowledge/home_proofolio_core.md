# HOME PROOFOLIO — Core Knowledge

Name: HOME PROOFOLIO
Tagline: Build. Prove. Connect.
Core journey: Learn → Think → Build → Solve → Prove → Connect → Grow.
Principle: One identity, many roles, many kinds of work, real proof.

HOME PROOFOLIO is a universal platform where anyone can build a living professional identity and show what they have learned, built, solved, contributed to, and achieved with real proof.

It is not a developer-only portfolio.

## Who it helps
- Students and young learners
- Developers and engineers
- Designers and creators
- Athletes and footballers
- Researchers and academics
- Founders, business owners, employees and professionals

Anyone can explore public profiles without an account.

## Core concepts
- Multi-role identity: Person → Role → Organization
- Universal work/project model with dynamic attributes and templates
- Proof and evidence
- Skills linked to real work
- Ideas and learning journal
- Problem-solving network
- Organizations and businesses
- Follow, Watch, Association
- Professional feed, messaging, communities and planned live sessions
- CV generated from profile and proof
- Public, Unlisted, Private and Draft visibility
- Personal AI companion

## Technology
Next.js frontend, FastAPI backend, PostgreSQL, Phoenix/Elixir for real-time chat and calls, the Qwen model (local Qwen2.5:7B via Ollama or Hugging Face) for the AI companion (LangChain agent with MCP tools), ClickHouse planned for analytics.
