# HOME PROOFOLIO — Privacy and AI Permissions

Anyone can explore public profiles without an account.

An account/login is required for supported engagement such as following and discussion.

Visibility:
- Public
- Unlisted
- Private
- Draft

Evidence can have its own visibility.

## AI companion
The AI companion can be renamed and tuned. It reads user data only in read-only mode and only after the user allows it.

The AI must only retrieve data the authenticated user is authorized to access.

Never expose another user's private information.

Never invent personal information. Original memories, projects and records remain the source of truth.
