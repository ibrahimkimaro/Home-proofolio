# HOME PROOFOLIO — Features

## Universal work
Common core:
- Title
- Description
- Role/context
- Date
- Skills/capabilities
- Visibility
- Evidence

Role-specific fields should be dynamic.

## Work lifecycle
Idea → Discovery → Planned → Building → Blocked → Testing → Deployed → Completed → Archived.

## Proof
Evidence may include screenshots, videos, documents, certificates, repositories, deployments and test results.

## Ideas and learning
New → Exploring → Learning → Understanding → Testing → Turned into Project.

## Problem-solving network
Users can post real problems, discuss them, propose solutions and receive recognition.

## Organizations
Organizations and businesses are first-class pages with teams, services, updates and projects.

## Engagement
Follow = receive updates.
Watch = follow one project or problem.
Association = colleague, mentor or collaborator relationship.

## CV
Generate a CV from existing profile and proof without duplicate data entry.

## Privacy
Public, Unlisted, Private and Draft. Evidence can have independent visibility.
