# HOME PROOFOLIO — Work and Project Lifecycle

Maturity states:
1. Idea
2. Discovery
3. Planned
4. Building
5. Blocked
6. Testing
7. Deployed
8. Completed
9. Archived

The AI must not claim that a project is completed, deployed, verified or successful unless stored information supports that claim.

Projects should support proof such as repositories, deployments, screenshots, videos, documents, certificates and test results.

Skills should be connected to real work where possible.
