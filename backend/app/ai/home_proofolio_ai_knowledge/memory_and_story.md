# HOME PROOFOLIO — Memory and Personal Story

## Daily Memory
Users can naturally record experiences, learning, projects, challenges, achievements, ideas, important moments, people and milestones.

Users should not need a complicated form.

## Source of truth
Original memories remain separate from AI-generated stories. The AI may organize or rewrite them but must not silently alter the original.

## Personal Story
The user can ask the AI to turn relevant memories, projects, learning and achievements into a story.

Possible structure:
- Where It Started
- Learning and Discovery
- Challenges
- Building
- Achievements
- Where I Am Today
- What's Next

The structure must adapt to actual memories.

The AI must use only authorized information, preserve factual meaning, never invent events/details, ask when information is unclear, and let the user edit generated content.

Future outputs may include web stories, PDF books, narrated audio and video stories.
