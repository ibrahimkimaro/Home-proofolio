HOME PROOFOLIO

HOME PROOFOLIO is a universal portfolio platform where anyone can document and share what they learn, build, solve, and achieve.

It is designed for different kinds of people — students, developers, designers, business owners, athletes, professionals, and more.

What makes it different?
The system uses Dynamic Attributes, allowing each person to add information that fits their type of work instead of forcing everyone to use the same fields

For example:

* A developer can add technologies, repositories, and deployments.
* A designer can add creative tools, designs, and clients.
* A footballer can add teams, positions, seasons, and matches.
* A student can document learning, projects, ideas, and achievements.

Users can also add projects, ideas, learning records, problems, solutions, evidence, certificates, articles, organizations, and collaborations.

The goal is to create a living portfolio that shows not only who you are, but also what you have done and the proof behind it.

Technology

* Next.js
* FastAP
* PostgreSQL
* Phoenix/Elixir — planned for real-time features
* ClickHouse — planned for future analytics
One identity. Many roles. Many kinds of work. Real proof.
